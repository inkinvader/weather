## Proposed personality weighting scheme

**Style tags.** Each of the 3 outfit variations per category gets one tag describing its vibe. Personality then favors the variations whose tag matches it. The tags would be:

| Tag | Example (Mild category) |
|---|---|
| **sporty** | joggers, tank or tee, ball cap |
| **relaxed** | loose hoodie, sweats, beanie |
| **sharp** | fitted layers, jeans, tidy jacket |
| **bold** | ripped jeans, loud pattern, cowboy or bucket hat |

Each category has 3 variations, so some tags are left out per category.

**Weights.** Each variation starts at weight 1. A variation matching the character's favored tags gets weight **3**. All the weights are then used in a seeded weighted pick. With two favored tags and three variations, that puts a favored style at roughly 60% to 75% and an unfavored one at 10% to 25%. That's clearly visible over many draws, but never certain.

| Personality | Favored tags |
|---|---|
| energetic | sporty, bold |
| anxious | sharp, relaxed |
| grumpy | relaxed, bold |
| chill | relaxed, sporty |
| neutral | none (all weights equal, so uniform) |

**How it fits the rest of the design**
- The pick is seeded from (location, date, character ID) as the spec requires. Weighting changes only the probabilities, so the same inputs always give the same outfit.
- The tag for each variation lives in a small data table, so checkpoint 4 doesn't depend on the art existing yet.
- Tests run thousands of draws to check that, for example, energetic skews toward sporty and bold, neutral stays roughly even, and no variation ever has zero chance.
